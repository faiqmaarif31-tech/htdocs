# Praktikum 7 PHP — Versi Satu File

Semua latihan 1–7, mini project, eksperimen mandiri, dan evaluasi digabung dalam satu file `index.php`.

## Menjalankan
1. Ekstrak folder `Lab7Web_PHP_Satu_File`.
2. Pindahkan folder ke `C:\xampp\htdocs\`.
3. Jalankan Apache dari XAMPP.
4. Buka `http://localhost/Lab7Web_PHP_Satu_File/`.

Pilih materi melalui menu navigasi di sisi kiri. Pastikan dibuka melalui localhost, bukan klik ganda file.
